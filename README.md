# IE-7615 Generative Project

Text-to-image generation using a Transformer text encoder (CLIP) and a pre-trained diffusion model (Stable Diffusion v1.5).
Course: IE 7615 Deep Learning for AI.

## Status
Milestone 1 (project setup and dataset preparation): complete.

## Repository structure
- `data/`: `manifest.csv` (2,000 image–caption pairs) and `preprocessing_config.json`
- `notebooks/`: Colab notebooks (see run order below)
- `results/`: token statistics and embedding config
- `src/`: reusable code (added in later milestones)

## Setup
Developed and tested on Google Colab with a T4 GPU.

    pip install -r requirements.txt

Pinned versions: torch, diffusers, transformers, accelerate.

## How to run
Run the notebooks in `notebooks/` in this order:
1. `Milestone1_generative.ipynb`: downloads COCO val2017 captions, selects 2,000 pairs (seed 42), resizes and center-crops images to 512×512 RGB, and writes `manifest.csv`.
2. `02_text_embeddings.ipynb`: loads the CLIP text encoder from the Stable Diffusion v1.5 checkpoint and embeds all 2,000 captions.

Both notebooks expect their working folder at `MyDrive/IE_7615_generative/data` on Google Drive.
